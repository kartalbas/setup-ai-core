# Glossary

One concept, one word, everywhere: in code, configuration, documents and messages to a person. A
new name enters this file in the same change that introduces it, with its one meaning and the place
it lives (a file, a table, a screen). A word that is spelled two ways is listed under "Contested"
until somebody decides it, and the decision moves it up. `ai-core init` puts this file into every
checkout as `.ai-core/docs/<harness>/glossary.md`; it is edited here, in the project harness, and
`ai-core push` delivers it.
